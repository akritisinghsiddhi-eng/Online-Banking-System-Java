# Online Banking System

## Project Description

The Online Banking System is a Java-based project developed to demonstrate basic banking operations using Java, MySQL, and JDBC.

## Requirements

- Java JDK 8 or above
- MySQL Server
- MySQL Workbench
- Java IDE (IntelliJ IDEA, Eclipse, or VS Code)
- MySQL JDBC Connector

## Project Setup

1. Open the project in a Java IDE.
2. Make sure Java JDK is properly installed.
3. Install and start MySQL Server.
4. Create the required database in MySQL.
5. Configure the database username, password, and database name in the Java database connection code.
6. Make sure the MySQL JDBC Connector is added to the project.
7. Compile the Java files.

## How to Run

1. Open the project in your Java IDE.
2. Configure the MySQL database connection.
3. Run the main Java class.
4. The Online Banking System will start successfully.

## Technologies Used

- Java
- MySQL
- JDBC
- GitHub

## Features

- User Login
- Account Management
- Check Account Balance
- Deposit Money
- Withdraw Money
- Money Transfer
- Database Connectivity

## Purpose

This project is developed for educational purposes to understand Java programming, Object-Oriented Programming, JDBC, SQL, and database connectivity.
